# Laboratorio: comportamiento de una función

Explorador interactivo de *f*, *f′* y *f″* — extremos, concavidad, asíntotas y graficado — para el curso
**Cálculo I (20252)**, Escuela de Matemáticas, Universidad Industrial de Santander.

- Catálogo de funciones tomado de la *Miscelánea de aplicaciones de la derivada*, capítulo 3 (ejercicios 116–190).
- Parámetros de URL: `?f=180` (carga el ejercicio 180), `&embed=1` (modo compacto para Moodle), `&tab=signos|asintotas|plan|teoria`, `&capas=fp,fpp`.
- Un solo archivo (`index.html`); usa KaTeX y, en modo libre, math.js desde CDN.
